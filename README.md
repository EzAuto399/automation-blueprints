## The pattern (same every episode)

1. **Enquiries come in** from every channel, at all hours.
2. **AI staff draft the reply** using the business's own information (listings, policies, documents).
3. **A human approves** before anything sensitive goes out.
4. **The loop runs every day** — posting, chasing, reminding, booking — so nothing slips.
